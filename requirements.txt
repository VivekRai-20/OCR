# IMPORTANT — Python version requirement:
#   PaddlePaddle ONLY supports Python 3.8, 3.9, 3.10, 3.11, 3.12.
#   Python 3.13 and 3.14 are NOT supported.
#
#   Recommended: Python 3.11
#   Download: https://www.python.org/ftp/python/3.11.9/python-3.11.9-amd64.exe
#
# Setup (recommended order):
#   1. Install Python 3.11 from python.org
#   2. py -3.11 -m venv .venv
#   3. .venv\Scripts\activate
#   4. pip install -r requirements.txt
#
# GPU note:
#   The default installs CPU PaddlePaddle.
#   For GPU (CUDA 11.x), replace paddlepaddle with:
#     pip install paddlepaddle-gpu==2.6.2 -f https://www.paddlepaddle.org.cn/whl/windows/mkl/avx/stable.html
#
# Poppler (required for PDF processing, NOT installed by pip):
#   Windows: https://github.com/oschwartz10612/poppler-windows/releases
#   Extract and add the bin/ directory to PATH, or set pdf.poppler_path in config.yaml.
#   Linux:   sudo apt install poppler-utils
#   macOS:   brew install poppler
# =============================================================================
